# Beyond Tool Accuracy: End-to-End Reliability of On-Device SMS Agents Under Homoglyph Attacks

This repository hosts the project page for our paper, presented at the
**NeurIPS 2026 Workshop on Agents in the Wild: Safety, Security, and Beyond**.

Cheng-Che Lee, Chia-Pin Cheng, Hsu-Sheng Chang, Chia-Lin Chou
Digital Innovation Laboratory, Chunghwa Telecom Laboratories, Taoyuan, Taiwan

[[Paper]](https://openreview.net/pdf?id=k0tisYvu30) [[OpenReview]](https://openreview.net/forum?id=k0tisYvu30)

**TL;DR:** We fix a homoglyph-attack vulnerability in lightweight URL classifiers via CHT loss
(homoglyph detection ~9% → 96%), then show that whether the fix reaches the agent's decision depends
on the host LLM: one host follows the tool, two override it.
